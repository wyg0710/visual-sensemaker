# Examples

Every example is a self-contained, editable SVG with no remote fonts, scripts, images, or tracking resources.

## Visual Sensemaker workflow

Prompt:

> Explain how Visual Sensemaker turns complex source material into a clear, editable visual. Show the workflow and several broad use cases on one landscape canvas.

Output:

- `visual-sensemaker-workflow.svg` is the editable source and rendered example.

The example demonstrates a workflow diagram with grouped use-case cards. It intentionally uses only portable SVG elements and system fonts.

## Problem-solving process

Prompt:

> Turn “identify the problem → gather information → analyze causes → develop a plan → execute → review” into a clear, editable Chinese SVG flowchart.

Output:

- `problem-solving-process.svg`

Why this structure: the source is an explicit ordered sequence, so a left-to-right flowchart preserves the relationship with minimal interpretation.

## Learning concept map

Prompt:

> Create a one-page Chinese concept map showing five related parts of effective learning: clear goals, active input, processing for understanding, output for checking, and reflective adjustment.

Output:

- `learning-concept-map.svg`

Why this structure: the five ideas support one center topic rather than forming a strict timeline.

## Task-tool comparison

Prompt:

> Compare paper, spreadsheets, and specialized task tools across the same three criteria: strengths, limitations, and suitable situations. Make the assumptions explicit and keep the SVG editable.

Output:

- `task-tool-comparison.svg`

Why this structure: three alternatives share the same criteria, so aligned comparison cards make differences easy to scan without inventing a numerical ranking.
